# Taller Delay "Daisy" Workshop enero 2026

***

## Descripción.

Repositorio que reúne los conocimientos entregados en el Workshop "Taller Delay".
En este se enseñará a programar un efecto de delay en c++ para luego implementarlo en una placa [Daisy](https://electro-smith.com/products/daisy-seed) y como parte final construir una interfaz con sensores para controlar el efecto.

Este intensivo es impartido por [Emir Chacra](https://emirchacra.com/), [Aarón Montoya](https://montoyamoraga.io/) y [Carolina Espinoza](https://sites.google.com/view/caroespinoza/inicio?authuser=0).
